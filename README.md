# Stevens - голосовой ассистент для задач, встреч и напоминаний
Stevens помогает управлять делами на русском языке: принимает голосовые и текстовые запросы, создаёт задачи и встречи, показывает планы и находит ранее сохранённые записи. Если данных недостаточно, задаёт уточняющий вопрос; если время занято - предлагает варианты решения.

**Прототип:** https://stevens-trial.duckdns.org/
Попробовать приложение можно после регистрации или без неё (в отдельной песочнице с 1000 событиями из датасета задания)

## Локальный запуск
Потребуется **Docker Desktop с поддержкой Linux-контейнеров**. Команды выполняются из корня репозитория.

### 1. Подготовьте настройки

Скопируйте `.env.example` в `.env`.

**Windows PowerShell:**

```powershel
Copy-Item .env.example .env
```

**Linux / macOS:**

```bash
cp .env.example .env
```

Для подключения YandexGPT и SpeechKit заполните в `.env`:

```dotenv
YANDEX_API_KEY=ваш_API_ключ
YANDEX_FOLDER_ID=идентификатор_каталога
YANDEX_GPT_MODEL=yandexgpt
```

Сервисному аккаунту нужны роли `ai.languageModels.user`, `ai.speechkit-stt.user` и `ai.speechkit-tts.user`. Область действия ключа должна разрешать соответствующие сервисы.

**Без ключей доступны основные текстовые сценарии на локальных правилах.** Облачное распознавание, озвучка SpeechKit и разбор через YandexGPT требуют настроенных ключей и доступа к интернету.
Файл `.env` исключён из Git. Ключи используются только на сервере.

### 2. Запустите приложение

```bash
docker compose up -d --build
```

Первый запуск может занять несколько минут. Порты `8080`, `8000` и `5433` должны быть свободны.

| Сервис | Адрес |
|---|---|
| Приложение | http://localhost:8080 |
| Документация API | http://localhost:8000/docs |
| Проверка сервера | http://localhost:8000/api/health |




## Как устроен Stevens

**Интерфейс:** React, TypeScript, Vite и nginx.  
**Сервер:** Python, FastAPI, SQLAlchemy и PostgreSQL 16.  
**Понимание речи и текста:** локальные правила, морфология pymorphy3 и YandexGPT.  
**Голосовые сервисы:** браузерные API и Yandex SpeechKit.

Типовые запросы обрабатывают локальные правила. Для сложных и неоднозначных формулировок подключается YandexGPT. Сервер проверяет результат, ведёт контекст диалога и выполняет действия - модель не изменяет базу самостоятельно. Ответы формируются по шаблонам.

В поддерживаемых браузерах голосовой ввод сочетает промежуточную браузерную расшифровку с итоговым распознаванием SpeechKit. Для озвучки используется SpeechKit с браузерным резервом при сбоях.

Docker Compose запускает фронтенд, бэкенд, PostgreSQL и сервис резервного копирования базы.
